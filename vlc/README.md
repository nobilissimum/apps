### Disable auto-resize to video size

- Click **Tools** tab
- Select **Preferences**
- Enable _All_ in **Show settings** at bottom left of the window
- Expand **Interface** section
- Expand **Main interfaces** section
- Select **Qt**
- Uncheck **Resize interface to the native video size**

### Change skin

- Click **Tools** tab
- Select **Preferences**
- Enable _All_ in **Show settings** at bottom left of the window
- Expand **Interface** section
- Expand **Main interfaces** section
- Select **Skins**
- Select your downloaded skin file
